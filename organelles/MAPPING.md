# system-ontology — organelle mapping decisions (Tier C, declared)

Docs-only repo: the System Ontology scaffold (primitives, relations, valence
rules). No executable capabilities exist to decompose.

## Decision

- **Tier C declared.** One manifest (`system-ontology.manifest.json`, 15
  contracts covering the ontology primitives) with honest Candidate valence.
  No live host registration — there is nothing to execute.
- **Reference check:** the contracts describe ontology *definitions*, not
  computations. None of the 12 reference organelles applies (they are all
  executable units; this repo defines the vocabulary other organelles'
  contracts are written in).
- **Deliberate non-decomposition:** splitting prose definitions into fake
  "units" would be exactly the blind templating the doctrine forbids. One
  honest declared manifest is the correct shape.
